## 📋 About

MPGR HUB is an **AI-powered on-chain engagement platform** that lets you earn XP, complete quests, and build your onchain reputation on Base. Join the MoneyPaiger ecosystem and unlock exclusive rewards while climbing the leaderboard.

---

- 🔐 **Wallet Connect** — Secure connection with RainbowKit

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm or yarn

### Setup

1. **Get WalletConnect Project ID**
   - Visit: https://cloud.reown.com
   - Create a new project

2. **Clone & Install**
   ```bash
   git clone https://github.com/munazir17/MPGR-HUB.git
   cd MPGR-HUB
   npm install
   ```

3. **Configure Environment**
   ```bash
   cp .env.example .env.local
   # Fill in your WalletConnect Project ID and other variables
   ```

4. **Start Development**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.
