MPGR HUB — Agent send / Basename fix
====================================

Termux se upload:
1. Is zip ko project root pe extract karo (files overwrite hongi).
2. git add -A && git commit -m "fix: resolve Basenames on Base L2 and handle send on Gemini fallback"
3. git push origin main
4. Vercel auto-deploy.

Vercel env (Production + Preview) check karo:
- GEMINI_API_KEY = billed Google AI Studio / Vertex key
  Free-tier gemini-3.5-flash ~20 requests/day. Iske baad agent
  "I can help with: Portfolio Summary..." wala canned reply deta hai.
- BASE_RPC_URL = paid Base RPC (Alchemy paid / Infura / QuickNode)
  Free Alchemy CU khatam hone par reads fail ho sakte hain.
- MAINNET_RPC_URL optional. Ab Basename pehle Base L2 resolver se
  resolve hota hai, isliye Ethereum public RPC ki zaroorat nahi.

Kya issue tha:
1. "Basename resolution failed for jesse.base.eth"
   Code Ethereum mainnet pe CCIP-Read karta tha
   (publicnode / 1rpc). Yeh public RPCs Basename gateway fail karte
   hain. Gemini/Alchemy free tier is error ka direct cause nahi —
   galat chain + public ENS RPC hai. jesse.base.eth VALID hai
   (0x2211d1D0020DAEA8039E46Cf1367962070d77DA9).

2. 0x address se retry pe generic help
   Pehli call ke baad Gemini free-tier 429. Fallback deterministic
   provider send/transfer ko samajhta hi nahi tha, isliye portfolio
   FAQ dump aa jati thi.

Kya fix hua:
- Basename pehle Base L2 Resolver (0xC6d566...) se resolve.
- Mainnet ENS sirf fallback.
- 40-hex bina 0x bhi address maana jata hai.
- Gemini down ho to bhi "Send 0.000001 ETH to ..." transfer_prepare_send
  tool chalata hai, FAQ nahi.
