# MPGR Staking System

## Overview

The MPGR Staking System is designed to reward long-term holders while maintaining a sustainable emission model.

The system is fully funded by the Community Treasury.

No new MPGR tokens are ever minted.

All rewards come from the allocated staking treasury.

# Reward Model

Rewards are distributed dynamically.

There is NO fixed APY.

APR adjusts automatically depending on:

Total MPGR Staked

Available Reward Treasury

Community Participation

Governance Decisions

Seasonal Campaigns

---

# Reward Calculation

Rewards are proportional to:

User Stake

Time Staked

Total Pool Size

Reward Emission Rate

---

# Claim Rules

Rewards can be claimed at any time.

Only earned rewards are claimable.

Claiming rewards never affects the user's stake.

---

# Unstaking

Users may unstake any amount.

Unstaking automatically updates reward calculations.

Future governance may introduce optional cooldown periods.
