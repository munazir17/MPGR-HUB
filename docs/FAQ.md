# Frequently Asked Questions (FAQ)

Version: 1.0

---

# What is MPGR HUB?

MPGR HUB is an AI-powered Web3 ecosystem built on Base that combines staking, rewards, gaming, portfolio management, and future governance into one unified platform.

---

# What is MPGR?

MPGR is the native utility token powering the MPGR HUB ecosystem.

It is used for:

- Staking
- Rewards
- Gaming
- Premium features
- Governance
- Future AI ecosystem

---

# Which blockchain does MPGR use?

MPGR is deployed on the Base network.

---

# What is the total supply?

Maximum Supply

1,000,000,000 MPGR

The supply is permanently fixed.

No additional tokens can be minted.

---

# Is MPGR inflationary?

No.

MPGR has a fixed maximum supply.

There is no inflation.

There is no future minting.

---

# How are rewards funded?

All rewards are funded from the Community Treasury.

Rewards are not created through inflation.

---

# Can I stake MPGR?

Yes.

Live staking will be introduced as part of the Phase 3E development roadmap.

---

# Will there be governance?

Yes.

Future versions of MPGR HUB will introduce community governance for treasury and ecosystem decisions.

---

# Is there a mobile app?

Not yet.

The current focus is the web platform, with mobile support planned for the future.

---

# Is MPGR open source?

Parts of the ecosystem may become open source over time.

Project documentation is maintained publicly through the repository.

---

# Does MPGR HUB support AI?

Yes.

AI is a core pillar of the ecosystem and will expand over future releases.
